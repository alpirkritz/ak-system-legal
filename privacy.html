Privacy Policy

AK System is a private, single-user tool. Data is stored on a server owned by its operator and is never sold, shared with, or disclosed to third parties.

The "AK System Backup" Google OAuth app requests a single scope, drive.file. It can only access files and folders it created itself in the operator's own Google Drive, where it stores encrypted (age) backups of the operator's own data. It does not read, list, or modify any other file in Drive, and Google user data is not used for any other purpose.
